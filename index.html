Sharing with other people

Anyone can open this page's link and create their own account (email and password, or Google). Each account's data is completely private and separate — nobody can see or affect anyone else's ledger. Signing in on a new device with the same email and password (or the same Google account) brings back that person's own data automatically.

Backup

Keep a backup file regardless of sync status. It is the safest way to move data anywhere.
